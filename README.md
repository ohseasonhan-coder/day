# 쌤워크 SaemWork

> 선생님은 짧게 기록하고, 문서는 자동으로 쌓입니다.

어린이집 교사가 하루 동안 남긴 짧은 기록을 바탕으로 관찰일지, 보육일지, 부모상담자료, 발달평가, 놀이평가, 안전·행사평가 초안을 정리하는 교사용 실무 앱입니다.

이 프로젝트는 외부 AI API 키 없이 동작합니다. 기록 정리, 카테고리 분류, 발달영역 매핑, 표현 순화, 문서 초안 생성은 모두 브라우저 안의 규칙 기반 엔진으로 처리됩니다.

## 현재 완성 범위

- 아이 등록 및 반 설정
- 짧은 기록 입력
- 오타·띄어쓰기·조사 정규화
- 대표 카테고리 자동 분류
- 발달영역 자동 매핑
- 세부 태그 자동 생성
- 부정적 표현 순화
- 관찰일지 문장 생성
- 부모상담/알림장 문장 생성
- 교사 지원계획 생성
- 기록 수정·삭제
- 원문 수정 시 자동 재분류
- 문서작성 준비 메타데이터 저장
- 오늘 보육일지 초안 생성
- 주간·월간 놀이평가 초안 생성
- 부모상담자료 초안 생성
- 발달평가 초안 생성
- 안전·행사평가 초안 생성
- 교사교육일지 초안 생성
- 원장 검토자료 초안 생성
- 생성 문서 초안 로컬 저장
- 기록 누락 및 카테고리 균형 점검

## 기술 구조

- Frontend: React 18
- Local AI Engine: `src/utils/ai.js`
- Storage: browser `localStorage`
- Deployment: Vercel

## 실행

```bash
npm install
npm start
```

## 빌드

```bash
npm run build
```

## 주요 화면

| 화면 | 역할 |
|---|---|
| 오늘 | 오늘 기록 현황, 빠른 실행 |
| 기록하기 | 아이별 짧은 기록 입력 및 자동 정리 |
| 아이들 | 아이별 기록 조회, 성장요약, 상담자료 |
| 문서함 | 보육일지 및 실무 문서 초안 생성 |
| 점검 | 기록 누락, 카테고리 균형, 평가제 준비 점검 |
| 설정 | 반/아이/자동화 기본 설정 |

## 다음 개발 준비

현재 기록에는 `documentMeta`가 함께 저장됩니다. 이 구조를 바탕으로 다음 기능을 붙일 수 있습니다.

- 문서 초안 수정 화면
- 문서별 저장함
- Word `.docx` 다운로드
- 우리 원 서식 등록
- 서식 자동 채움
- HWP 호환 출력
- 원장 검토/승인 흐름
- 평가제 점검표 자동 작성

## 원칙

- 외부 API 키가 없어도 사용 가능해야 합니다.
- 기록은 짧게 입력하고, 문서는 자동으로 축적되어야 합니다.
- 아이를 판단하지 않고 관찰 사실과 교사 지원 방향 중심으로 표현합니다.
- 생성 결과는 교사가 언제든 수정할 수 있어야 합니다.
