# 쌤워크 (SaemWork)

> 선생님은 기록만, 문서는 앱이.

어린이집 교사가 짧게 남긴 하루 기록을 바탕으로 관찰일지, 보육일지, 부모상담자료, 발달평가, 놀이평가 문서를 자동으로 정리해주는 AI 실무 앱입니다.

## 주요 기능 (MVP)

- **기록 자동 분류**: 짧은 관찰 메모 → AI가 카테고리, 발달영역, 세부태그 자동 분류
- **부정 표현 순화**: "산만하다" → "관심이 다양한 방향으로 이동하는 모습" 자동 변환
- **문서 3종 자동 생성**: 관찰일지용 / 부모상담용 / 지원계획 한 번에 생성
- **보육일지 자동 작성**: 오늘 기록 → AI가 보육일지 초안 생성
- **아이별 성장 요약**: 기간별 기록 요약 및 상담자료 자동 생성
- **누락 점검**: 기록 없는 아이, 부족한 카테고리 체크

## 기술 스택

- **Frontend**: React 18
- **AI**: Anthropic Claude API (claude-sonnet-4)
- **Storage**: localStorage (브라우저 로컬 저장)
- **배포**: Vercel

## 시작하기

### 개발 환경

```bash
npm install
npm start
```

### 배포 (Vercel)

```bash
npm run build
vercel deploy
```

또는 GitHub 연동 → Vercel 자동 배포:
1. GitHub에 push
2. Vercel에서 저장소 import
3. Build Command: `npm run build`
4. Output Directory: `build`

## API 키 설정

앱 실행 후 설정 → AI 설정에서 Anthropic API 키를 입력합니다.
- https://console.anthropic.com 에서 발급
- API 키는 브라우저 로컬에만 저장됩니다

## 화면 구성

| 화면 | 설명 |
|------|------|
| 오늘 | 오늘 기록 현황, 빠른 실행 |
| 기록 | 아이별 관찰 기록 입력 + AI 처리 |
| 아이들 | 아이별 기록 조회, 성장 요약, 상담자료 |
| 문서함 | 날짜별 보육일지 생성 |
| 점검 | 누락 기록 및 카테고리 균형 확인 |

## 개발 로드맵

### MVP (현재)
- 아이 등록, 기록 입력, AI 자동 분류
- 보육일지 생성, 아이별 성장 요약
- 누락 체크

### 2차 개발
- 주간/월간 놀이평가 자동 작성
- 발달평가 초안 생성
- Word(.docx) 다운로드
- 우리 원 서식 등록

### 3차 개발
- 안전교육일지, 행사평가, 교사교육일지
- 평가제 준비 체크리스트
- 원장 검토/승인 워크플로우
