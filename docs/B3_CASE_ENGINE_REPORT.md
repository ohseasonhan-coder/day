# B3 사례기반 문장 생성 엔진 검증 보고서

## 1. B2와 B3의 차이

B2는 사실 카드, 허용 테마, 금지 주장, 관찰내용, audit, fallback을 결정하는 안전 엔진이다. B3는 이 결정을 변경하지 않고 비식별 사례와 테마별 골격에서 배움 읽기와 지원 계획 후보를 만든 뒤 안전 후보 안에서만 표현을 선택한다.

`B2 사실 카드 -> B2 문장 계획 -> B3 사례 검색 -> 후보 생성 -> 안전 우선 재순위화 -> B2 audit -> B3 채택 또는 B2 fallback`

B3 flag 기본값은 OFF다. B3가 켜져도 정보가 부족하거나 사례·안전 후보가 없거나 audit 중대 오류가 발생하면 B2 결과를 그대로 사용한다.

## 2. 사례 라이브러리

사례는 `themes`, `factsShape`, `learningPatternId`, `supportPatternId`, 두 문장 골격, 금지 주장, 품질 태그, 발화·또래·실제 지원·희박 입력·문서 유형 제약만 가진다. 실제 원문, 이름, 직접 발화, 생성 전문은 포함하지 않는다.

현재 27개 선언형 사례와 16개 테마 언어 묶음을 사용한다. 문장 구조와 의미 표현, 계획 표현은 분리되어 있다.

## 3. 유사 사례 검색

- primary theme: 58점, 포함만 된 경우 44점
- secondary theme: 22점
- 사실 형태 Jaccard 유사도: 최대 34점
- 직접 발화, 또래, 실제 교사 지원, 정보 부족 상태: 일치 가점·불일치 감점
- 문서 유형: 5점
- 58점 이상 상위 5개만 후보 생성에 사용

## 4. 후보 생성과 선택

배움 읽기는 테마 골격 5종과 의미 표현 3종, 유사 사례 골격, 발화·또래 전용 골격을 조합한다. 지원 계획은 B2가 허용한 지원 행동만 사용해 기본 5종과 사례 골격을 조합한다.

후보 지표는 evidence coverage, theme fit, section fit, naturalness heuristic, specificity, repetition penalty, forbidden penalty, overclaim penalty, support practicality다. 안전 점수 90점 미만 또는 audit 중대 오류 후보는 선택할 수 없다. 정렬 순서는 안전 통과, 안전 점수, 품질 점수, 후보 ID다.

## 5. 반복 감소

동일한 이름 치환·완성 문장 비교식에서 B2 표현 중복률은 40%, B3는 37%였다. 선택된 골격은 B2 4종에서 B3 23종으로 늘었다. 일반론 비율은 B2와 B3 모두 11%로 같아 이번 단계에서 일반론 자체가 감소했다고 판단하지 않는다.

## 6. 로컬 피드백

저장 항목은 테마 조합, learning/support pattern ID, 후보 점수, 선택 후보 ID, 선택형 피드백뿐이다. 그대로 사용은 +6, 자연스러움·지원 수정 요구는 -5, 사실과 다름은 -30으로 반영하며 전체 가중치는 -30~+12로 제한한다. 안전 점수 계산 뒤에만 더하므로 선호도가 안전 탈락 후보를 살릴 수 없다.

원문, 이름, 생성 전문, 발화 전문, 자유 메모는 저장하지 않으며 해당 로컬 키는 백업·동기화에서 제외한다.

## 7. 155건 자동 검증

| 항목 | 결과 |
|---|---:|
| 합성 사례 | 155건 |
| B3 채택 | 138건 |
| 평균 후보 수 | 30.3개 |
| 후보 안전 탈락률 | 0.4% |
| 유사 사례 검색 성공률 | 89% |
| 사례 후보 생성 사용률 | 89% |
| 최종 사례 골격 선택률 | 18% |
| B2 표현 중복률 | 40% |
| B3 표현 중복률 | 37% |
| B2/B3 일반론 비율 | 11% / 11% |
| 사실·발화 보존 | 100% |
| 정보 부족 보수 처리 | 100% |
| 선택 골격 수 | 23종 |
| 자동 품질 점수 | 98.7 |

자동 품질 점수는 구조·금지 표현·문장 완결성 검사 결과이며 실제 교사 선호도나 그대로 사용 가능 비율이 아니다.

## 8. 구조상 개선 사례

1. 오타가 있는 순서 기록: 일반적인 차례 문장 대신 `정해진 순서를 확인하며 자신의 차례를 기다렸다`로 선택.
2. 점토 만들기: 재료 일반론 대신 `점토를 다루는 과정`을 배움 문장에 반영.
3. 식판 정리: `일상 행동` 범주 안에서 직접 해 본 행동 중심 골격 선택.
4. 순차적 이야기: 사건과 말을 잇는 흐름과 그림·사진 순서 지원을 연결.
5. 긴 재시도 서사: 잘린 관찰 반복 대신 `뜻대로 되지 않은 뒤에도 다시 시도`한 흐름으로 축약.

이 사례들은 자동 기준에서 안전하고 반복이 줄어든 예시다. 교사가 B2보다 실제로 선호한다는 의미는 아니다.

## 9. B2 fallback이 더 안전한 사례

1. `오늘 등원했다`
2. `교실에 있었다`
3. `오전 자유놀이를 했다`
4. 구체 행동 없이 활동명만 있는 기록
5. 테마 근거가 없는 짧은 상태 기록

이 경우 B3는 배움 의미를 만들지 않고 B2 결과와 최대 2개의 보완 질문을 유지한다.

## 10. 코드만으로 어려운 영역

- 은유적 발화의 의도와 깊이 해석
- 긴 복합 서사에서 교사가 중요하게 보는 장면 우선순위
- 같은 행동이라도 반 맥락에 따라 달라지는 적절한 지원 강도
- 감정 단서의 미묘한 변화와 회복 시점
- 기관·교사별 자연스러운 문체 선호

이 영역은 자동 점수가 아니라 비식별 실제 교사 검토로 확인해야 한다.

## 11. 변경 및 배포 상태

B3 코드, 사례 라이브러리, 50건 추가 합성 데이터, 검토 메타데이터, 빠른 조정 연결, 설정 flag를 추가했다. 새 문서 유형, 외부 API, 외부 LLM, 모델 다운로드는 추가하지 않았다. main 병합, 원격 push, 배포는 수행하지 않는다.
