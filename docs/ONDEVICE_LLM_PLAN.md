# 데스크탑 온디바이스 LLM "자연스럽게 다듬기" 설계 (R&D 트랙)

> 목적: 규칙 조합 문장보다 **대화처럼 자연스러운 문장**. 단, **외부 전송 없이(개인정보 보호)** 사용자 기기에서만.
> 성격: **베타 이후 실험 트랙**. 현재 베타(모바일·규칙엔진) 경로는 **절대 변경하지 않는다**.

## 0. 핵심 원칙 (반드시 지킴)
- **기존 엔진 무변경**: `generateWithFallback`/composers/골든 테스트 경로는 그대로 둔다. LLM은 그 **위에 얹는 선택적 후처리 레이어**.
- **기본 꺼짐 + 게이트**: 기능 플래그 OFF가 기본. **데스크탑 + WebGPU 지원**일 때만 노출.
- **지연 로딩(lazy import)**: LLM 코드/모델은 **동적 import**로만. 모바일·일반 사용자 번들 크기에 영향 0.
- **외부 전송 0**: 모델 다운로드 후에는 네트워크 없이 동작(드라이브 백업과 무관, 외부 LLM API 아님).
- **사실/발화 보존 가드**: LLM은 창작·왜곡(민원 위험)이 있을 수 있으므로, 다듬은 결과를 **기존 품질 채점기(qualityScorer)로 검증** → 사실/발화 보존 실패 시 **규칙 결과로 자동 되돌림**.

## 1. 기술 접근 (2안 비교, 우선순위 순)
1. **Chrome 내장 Prompt API (Gemini Nano)** — `window.ai`/`LanguageModel`
   - 장점: **모델 다운로드 없음**(브라우저 내장), 가장 가벼움.
   - 단점: **데스크탑 크롬 한정·실험적(플래그/Origin Trial)**, 한국어 품질 확인 필요, 가용성 불확실.
2. **WebLLM (@mlc-ai/web-llm) + WebGPU**
   - 장점: 모델 선택 가능(품질↑), 크롬/엣지 데스크탑.
   - 단점: **최초 1.5~2.5GB 다운로드**, WebGPU 필요, 메모리·로드시간.
   - 모델 후보(한국어): `Qwen2.5-3B-Instruct-q4f16` 또는 `gemma-2-2b-it-q4f16`.
- **전략**: Prompt API가 있으면 먼저 사용(다운로드 0) → 없으면 WebLLM로 폴백.

## 2. 통합 경계 (어디에 얹나)
- 기록 결과 화면에 **"✨ 자연스럽게 다듬기 (실험실 · 데스크탑)"** 버튼(데스크탑+WebGPU+플래그일 때만).
- 입력: 규칙엔진이 만든 문장 + 원본 메모(사실 근거).
- 처리: LLM에게 "사실/아이 발화를 바꾸지 말고 자연스럽게 다시 써라" 프롬프트로 **재작성**.
- 검증: `qualityScorer`로 factPreservation/speech 보존 확인 → **통과 시에만** 다듬은 문장 표시(없으면 원래 규칙 문장 유지).
- 저장/복사: 사용자가 채택한 문장만. (검수/실험 메타는 백업 제외 — 기존 정책)

## 3. 단계별 계획 (검증 먼저, 투자 나중)
- **Phase 0 — 가용성 감지(무의존성, 안전)**
  - `navigator.gpu`(WebGPU)·`window.ai`(Prompt API)·데스크탑 여부 감지 유틸 + 콘솔/설정에 "사용 가능 여부"만 표시. 의존성·모델 없음. **번들 영향 0**.
- **Phase 1 — POC(플래그 뒤)**
  - 데스크탑에서 모델 1개 로드 → 골든 비식별 샘플 10~20건을 "다듬기" → **자연스러움 향상 vs 사실/발화 보존**을 표로 측정. 품질이 충분한지 **결정**.
- **Phase 2 — 정식(조건부)**
  - Phase 1이 통과하면 결과 화면에 옵트인 버튼 장착(데스크탑·플래그). 모바일·기본 경로 무영향 유지.

## 4. 위험과 대응
| 위험 | 대응 |
|---|---|
| WebGPU/Prompt API 미지원 | 데스크탑·지원 환경에서만 노출, 아니면 기능 숨김 |
| 모델 다운로드 1~2GB | 최초 1회·명시적 동의·진행률 표시, 데스크탑 한정 |
| 한국어 품질 미달 | Phase 1에서 골든 샘플로 정량 측정 후 결정(미달 시 보류) |
| 사실/발화 왜곡(민원 위험) | qualityScorer 보존 가드 → 실패 시 규칙 문장 유지 |
| 번들·모바일 영향 | 동적 import + 플래그 + 환경 게이트로 완전 격리 |

## 5. 베타와의 관계
- 현재 **베타는 규칙엔진 그대로** 진행. 본 트랙은 **분리된 실험 기능**으로, 켜기 전엔 아무 영향 없음.
- 따라서 "엔진 대규모 변경 금지" 동결을 위반하지 않음(기존 경로 불변, 추가 레이어·기본 꺼짐).

## 6. 다음 액션
1. **Phase 0(가용성 감지)** 먼저 — 의존성 없이 "이 기기에서 온디바이스 LLM이 가능한가"를 확인하는 유틸 + 설정 표시. (안전, 번들 영향 0)
2. 가능 환경이 확인되면 **Phase 1 POC**로 실제 다듬기 품질을 측정해 투자 여부 결정.
