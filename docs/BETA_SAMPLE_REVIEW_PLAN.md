# 베타 전 문장 품질 검수 계획 (비식별 샘플)

> **생성 엔진은 변경하지 않습니다.** 이 문서는 검수 계획과 기록 양식만 정의합니다.
> 모든 입력은 **비식별 테스트 샘플**만 사용합니다(A원아/B원아 수준).

## 0. 절대 금지(개인정보)
- 실제 원아 이름·기관명·반명·가족 정보·건강 정보·구체 날짜·주소·사진 사용 금지.
- 식별 가능한 조합(이름+생일, 반명+사진 등)도 금지.
- 샘플은 "A원아", "B원아", "○○반", "△월 △주" 형태의 가공값만 사용.

## 1. 목표 수량
| 문서 유형 | 목표 검수 수 | 현재 골든 평균(참고) |
|---|---|---|
| 관찰일지 | 50 | 관찰계열 97.0 |
| 알림장 | 50 | 97.0 |
| 보육일지 평가 | 50 | 93.5 |
| 상담자료 | 30 | 95.7 |
| 발달평가 | 30 | 95.8 |
| **합계** | **210** | — |

## 2. 검수 기준(항목별 0~2: 미흡/보통/우수)
1. **사실 보존** — 입력 메모의 사실을 왜곡·창작 없이 반영
2. **발화 보존** — 따옴표 속 아이 발화가 변형되지 않음
3. **자연스러움** — 한국어 문체가 어색하지 않음
4. **부모 민원 위험 표현** — 단정·부정 낙인·비교 표현 없음(있으면 0)
5. **문서 목적 적합성** — 해당 문서(관찰/알림장/평가/상담/발달) 톤에 맞음
6. **반복 표현** — 같은 표현 과다 반복 없음
7. **바로 복사 가능 수준** — 교사가 손대지 않고 붙여넣어도 되는지

> 합격선: 항목 4(민원 위험) 0건 필수 + 총점 환산 85점 이상. 85 미만은 "수정필요"로 분류(엔진 변경이 아니라 입력 메모/샘플 보완 또는 베타 후 개선 항목으로 기록).

## 3. 비식별 샘플 시드 예시(형식)
```
[관찰일지] 입력: A원아가 블록으로 탑을 쌓다가 무너지자 "다시!"라고 말하며 다시 쌓았다.
[알림장]   입력: B원아가 친구에게 크레파스를 빌려주며 같이 그림을 그렸다.
[보육평가] 입력: ○○반 자유놀이 중 A원아가 역할놀이에서 의사 역할을 맡아 친구를 진료했다.
[상담자료] 입력: B원아가 최근 등원 시 분리불안이 줄고 인사를 먼저 한다.
[발달평가] 입력: A원아가 가위로 직선을 따라 자를 수 있게 되었다.
```

## 4. 기록 양식(검수자 1건당)

| 입력 메모(비식별) | |
| 생성 결과 요약 | |
| 1 사실보존 / 2 발화보존 / 3 자연스러움 / 4 민원위험 / 5 목적적합 / 6 반복 / 7 복사가능 | _ / _ / _ / _ / _ / _ / _ |
| 총평(합격/수정필요) | |
| 비고(개선 메모) | |

## 5. 진행/집계
- [ ] 관찰일지 50 (현재 0)
- [ ] 알림장 50 (현재 0)
- [ ] 보육일지 평가 50 (현재 0)
- [ ] 상담자료 30 (현재 0)
- [ ] 발달평가 30 (현재 0)
- 집계 시 유형별 평균·민원위험 건수·수정필요 건수 기록.

> 참고: 앱 내 관리자(마스터) "엔진 검수 리포트"로도 누적 점수를 볼 수 있으나, 일반 사용자에게는 노출되지 않습니다.
