# RC1 모바일 실기기 QA 체크리스트

> 사람이 실제 모바일 기기에서 직접 수행하는 최종 QA 시트입니다.
> 각 항목을 통과하면 체크하고, 문제가 있으면 "비고"에 증상을 적어주세요.
> 자동화 테스트/코드 점검은 별도(`docs/RELEASE_CANDIDATE_QA_REPORT.md`)에서 끝났고, 이 문서는 **클릭 검증 전용**입니다.

## 0. 테스트 환경 기록
- 테스트 기기: ____________________ (예: 갤럭시 S23 / 아이폰 14)
- 화면 크기/해상도: ____________________
- 브라우저: ____________________ (예: Chrome 126, Safari 17)
- 앱 주소(배포 URL): ____________________
- 테스트 날짜: ____________________
- 테스트 담당자: ____________________
- 테스트 계정 유형: ☐ 신규 설치(데이터 없음)  ☐ 기존 데이터 보유  ☐ 관리자(master)  ☐ 일반 구글 계정

---

## 1. 첫 접속 / 온보딩
- [ ] 앱 주소 접속 시 로딩/첫 화면이 깨지지 않고 표시된다
- [ ] 첫 접속 시 온보딩(3단계)이 표시된다
- [ ] 온보딩 단계 이동(다음/이전/건너뛰기)이 정상 동작한다
- [ ] 온보딩 완료 후 다시 접속하면 온보딩이 재노출되지 않는다

## 2. 계정 / 인증
- [ ] (운영) 관리자 첫 로그인 시 비밀번호 미설정 상태 안내가 보인다
- [ ] 관리자 최초 비밀번호를 직접 설정하고 로그인된다
- [ ] 설정한 비밀번호로 재로그인된다 (틀린 비밀번호는 거부된다)
- [ ] 일반 사용자 구글 로그인으로 계정 생성/로그인이 된다
- [ ] (기존 평문 계정 보유 시) 로그인 후에도 정상 동작하고, 같은 비밀번호로 재로그인된다
- [ ] 로그아웃이 정상 동작한다
- [ ] 재로그인 시 기존 데이터(기록/문서/원아)가 그대로 보인다

## 3. 원아 / 기록 입력
- [ ] 원아 등록이 된다 (빈 상태 안내 → 추가)
- [ ] 오늘기록 화면에서 원아 선택이 된다
- [ ] 오늘기록 텍스트 입력이 된다 (모바일 키보드 가림/스크롤 문제 없음)
- [ ] 빠른 예시 버튼(칩)을 누르면 입력칸에 예시가 들어간다
- [ ] 빈 입력으로 생성 시 안내 메시지가 뜬다

## 4. 문장 생성 / 결과 카드
- [ ] 문장 생성이 동작하고 로딩 표시가 보인다
- [ ] 관찰일지 카드가 표시된다
- [ ] 알림장 카드가 표시된다
- [ ] 보육일지 평가 결과가 표시된다
- [ ] 카드 접기/펼치기(▲/▼)가 동작한다
- [ ] 카드별 복사 버튼이 동작한다 (복사 토스트 노출)
- [ ] 전체 복사 버튼이 동작한다
- [ ] 복사한 내용이 **키즈노트**에 정상 붙여넣기 된다
- [ ] 복사한 내용이 **카카오톡**에 정상 붙여넣기 된다
- [ ] 복사한 내용이 **메모장**에 정상 붙여넣기 된다 (줄바꿈/형식 유지)

## 5. 문서함 / 저장
- [ ] 문서 저장이 된다
- [ ] 문서함(전체 기록)에서 저장한 문서를 다시 열 수 있다
- [ ] 다시 연 문서 내용이 저장 시점과 동일하다

## 6. 메뉴 / 설정
- [ ] 하단 더보기 메뉴가 열리고 스크롤된다
- [ ] 설정 화면이 열린다
- [ ] 설정 → "개인정보 저장 안내" 문구가 보인다
- [ ] 설정 → "공용 기기 사용 주의" 문구가 보인다
- [ ] 일반 사용자 화면 어디에도 관리자/검수 정보(엔진명·점수·fallback 사유·modular/legacy)가 보이지 않는다

## 7. 백업 / 복원 (구글 계정)
- [ ] Google Drive 백업이 동작한다 (최초 1회 동의 포함)
- [ ] Google Drive 복원이 동작하고 데이터가 돌아온다
- [ ] 복원 후 기록/문서/원아가 정상 표시된다

## 8. 오프라인 / 안정성
- [ ] 오프라인(비행기 모드) 상태에서 앱이 열린다
- [ ] 오프라인에서 기록 입력/문장 생성/저장 등 기본 기능이 동작한다 (로컬 기반)
- [ ] 오프라인에서 구글 백업 등 네트워크 기능은 안내와 함께 실패 처리된다(앱이 멈추지 않음)
