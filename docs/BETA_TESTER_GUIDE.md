# 쌤워크 베타테스터 안내문

안녕하세요, 선생님. 쌤워크 베타테스트에 참여해 주셔서 감사합니다.
이 안내문을 먼저 읽어주신 뒤 테스트를 시작해 주세요.

## 1. 쌤워크가 하는 일
선생님이 간단히 메모만 남기면, 앱이 **관찰일지·알림장·보육일지 평가** 등의 문장을 자동으로 만들어 드립니다.
모든 기록은 **선생님 기기에 저장**되고, 켜두신 경우에만 **선생님 본인의 Google Drive**에 백업됩니다. 외부 서버로 보내지 않습니다.

## 2. 테스트 기간
- 기간: ____________ ~ ____________ (운영자가 안내)
- 기간 중 자유롭게 사용하시고, 불편한 점을 피드백으로 남겨주세요.

## 3. 테스트해 볼 기능
- 원아 등록 → 오늘기록 입력 → 문장 생성
- 관찰일지/알림장/보육일지 평가 카드 확인 → 복사
- 문서 저장 → 문서함에서 다시 열기
- (선택) Google Drive 백업 / 다른 기기에서 가져오기(기기 간 동기화)

## 4. ⚠️ 실제 개인정보 입력 주의 (가장 중요)
> **테스트 중 실제 원아를 식별할 수 있는 이름, 사진, 주소, 건강정보, 가족상황 등은 입력하지 말아주세요. 검수가 필요한 경우 비식별 예시로 작성해주세요.**

- 이름은 "A원아", "○○이"처럼 가공해서 적어주세요.
- 반명·기관명·생년월일·연락처도 실제 값 대신 예시로 적어주세요.

## 5. 사진 업로드 주의
- 베타 기간에는 **실제 원아 사진을 올리지 말아주세요.** 꼭 필요하면 사람이 식별되지 않는 사물 사진으로 대체해 주세요.

## 6. Google Drive 백업 안내
- 백업을 켜면 선생님 **본인 Google Drive에만** 저장됩니다(앱이 만든 파일만 접근).
- 다른 기기에서 같은 Google 계정으로 로그인하면 설정 → "🔁 기기 간 동기화"에서 이어서 쓸 수 있습니다.
- 같은 내용을 양쪽 기기에서 동시에 많이 바꾸면 "충돌" 안내가 뜹니다. 안내에 따라 한쪽을 선택하시면 됩니다(자동으로 지우지 않습니다).

## 7. 공용 기기 사용 주의
- 공용 기기에서는 사용 후 **로그아웃**하고, 브라우저 저장 데이터를 삭제해주세요. 이 앱은 기록을 기본적으로 기기에 저장합니다.

## 8. 오류가 생기면 (기록 방법)
아래를 메모해 주시면 빠르게 확인할 수 있어요.
- 어떤 화면에서 / 무엇을 누르거나 입력했을 때 / 어떤 일이 일어났는지
- 사용 기기와 브라우저(예: 갤럭시 + 크롬)
- 가능하면 화면 캡처(개인정보가 보이지 않게)

## 9. 피드백 제출 방법
- `BETA_FEEDBACK_FORM.md`의 항목을 채워 운영자에게 보내주세요(운영자가 폼/링크 안내).
- 문장이 어색하거나 부모님께 보내기 부담스러운 표현이 있으면 꼭 알려주세요.

## 10. 테스트 종료 후 데이터
- 테스트 데이터는 선생님 기기(및 켜둔 경우 본인 Drive)에 남습니다.
- 정리를 원하시면: 설정에서 **로그아웃 + 브라우저 데이터 삭제**, Drive 백업 파일(`saemwork_backup.json`)은 본인 Drive에서 직접 삭제하시면 됩니다.
- 운영자는 선생님 데이터에 접근할 수 없습니다.

감사합니다. 선생님의 피드백이 더 편한 쌤워크를 만듭니다. 🙏
