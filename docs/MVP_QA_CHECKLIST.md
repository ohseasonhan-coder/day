# MVP 사용 흐름 QA 체크리스트

실제 사용 환경(모바일 우선)에서 핵심 흐름이 끊김 없이 동작하는지 점검한다.
모든 항목은 **외부 서버 없이 로컬/본인 구글 드라이브** 기준으로 확인한다.

> 표기: ✅ 통과 / ⚠️ 부분 통과(메모 필요) / ❌ 실패

## 1. 첫 사용자 온보딩
- [ ] 처음 로그인 시 온보딩 3단계가 표시된다 (원아 등록 → 한두 문장 → 복사).
- [ ] "다시 보지 않기" 또는 "시작하기"를 누르면 온보딩이 닫힌다.
- [ ] 다시 접속해도 온보딩이 다시 뜨지 않는다 (사용자별 localStorage 저장).

## 2. 원아 등록
- [ ] 원아가 없을 때 "아직 등록된 원아가 없어요…" 안내가 보인다.
- [ ] 설정에서 원아를 등록하면 기록 화면 아이 목록에 나타난다.
- [ ] 아이를 선택하지 않으면 "아이를 선택하면 아이별 기록으로 저장할 수 있어요." 안내가 보인다.

## 3. 기록 입력
- [ ] 입력이 비었을 때 생성 시 "아이의 모습을 한두 문장으로 적어주세요." 안내가 보인다.
- [ ] textarea에 상황을 자유롭게 입력할 수 있다.
- [ ] 기록 유형(관찰/알림장 등)을 선택할 수 있다.

## 4. 예시 버튼 사용
- [ ] 빠른 예시 칩(친구와 놀이/교사 지원 후 참여/감정 표현/안전교육/정리정돈/미술놀이)을 누르면 입력창에 추가된다.
- [ ] 기존 입력이 있으면 줄바꿈 후 자연스럽게 덧붙는다.

## 5. 문장 생성
- [ ] "AI 자동 정리하기"를 누르면 로딩 상태(스피너 + 안내)가 분명히 보인다.
- [ ] 관찰일지/평가/알림장/지원계획 문장이 생성된다.
- [ ] 생성 실패 시 "문장을 만들지 못했어요. 입력 내용을 조금 더 구체적으로 적어주세요." 안내가 보인다.

## 6. 결과 카드 접기/펼치기
- [ ] 관찰일지·알림장 카드는 기본 펼침 상태다.
- [ ] 보육일지 평가·지원계획 카드는 기본 접힘 상태다.
- [ ] 카드 헤더를 누르면 펼침/접힘이 전환되고 화살표 방향이 바뀐다.
- [ ] 빈 카드에는 "아직 생성된 문장이 없어요…" 안내가 보인다.

## 7. 카드별 복사
- [ ] 각 카드의 "복사" 버튼으로 해당 문장만 복사된다.
- [ ] 복사 성공 시 토스트가 뜬다.
- [ ] 복사 실패 시 "복사하지 못했어요. 문장을 길게 눌러 직접 복사해주세요." 안내가 보인다.

## 8. 전체 복사
- [ ] "결과 전체 복사"를 누르면 아래 형식으로 클립보드에 복사된다.
  ```
  [관찰일지 문장]
  …

  [보육일지 평가]
  …

  [알림장]
  …

  [교사 지원계획]
  …
  ```
- [ ] 빈 섹션은 복사 결과에서 제외된다.

## 9. 카드 편집
- [ ] 카드의 "편집"을 누르면 문장을 직접 수정할 수 있다.
- [ ] 수정한 내용이 저장 시 함께 저장된다.

## 10. 문서 저장 / 다시 열기
- [ ] "저장하기"로 기록이 저장되고 완료 토스트가 뜬다.
- [ ] 기록 목록(전체 기록)에서 저장한 기록을 다시 열 수 있다.
- [ ] 상세에서 관찰일지/평가/알림장 내용을 확인·복사할 수 있다.
- [ ] 문서함이 비어 있을 때 "아직 저장된 문서가 없어요. 오늘기록에서 문장을 생성하고 저장해보세요." 안내가 보인다.

## 11. 복사 이력
- [ ] 복사 이력이 없을 때 "복사한 문장이 여기에 표시돼요." 안내가 보인다.
- [ ] 복사한 문장이 이력에 쌓이고 다시 복사/입력 추가가 가능하다.

## 12. 모바일 화면 사용성
- [ ] 주요 버튼이 손가락으로 누르기 충분한 크기다(최소 높이 ~36px 이상).
- [ ] 카드 간격·줄간격이 충분해 긴 문장도 읽기 쉽다.
- [ ] 복사 버튼이 카드 헤더 우측에 고정되어 화면 밖으로 밀리지 않는다.
- [ ] 가로 스크롤(아이/유형 선택)이 자연스럽게 동작한다.

## 13. 관리자/검수 정보 비노출
- [ ] 일반 사용자 화면에 엔진명(legacy/modular)·품질 점수·fallback 사유·내부 라벨이 보이지 않는다.
- [ ] 엔진 비교/검수 리포트/전환 설정은 마스터(관리자) 계정 설정 화면에서만 보인다.

## 14. 백업/복원 기본 동작
- [ ] 구글 드라이브 자동 백업이 동작한다(연결된 경우).
- [ ] 백업 복원 시 아이/기록/문서/설정이 복구된다.
- [ ] 엔진 전환 설정(legacy/modular 플래그)만 동기화되고, 검수/fallback 데이터(개인정보 가능)는 백업에 포함되지 않는다.

## 출시 전 필수 시나리오
MVP 배포 직전, 아래 시나리오를 **모바일 실기기**에서 끝까지 한 번씩 통과시킨다.

1. [ ] 첫 접속 온보딩 확인 (3단계 → 시작하기/다시 보지 않기)
2. [ ] 원아 등록 (설정에서 등록 → 기록 화면 목록에 노출)
3. [ ] 기록 입력 (상황을 한두 문장으로 입력)
4. [ ] 예시 버튼 입력 (빠른 예시 칩 → 입력창에 추가)
5. [ ] 문장 생성 (관찰일지·알림장·평가·지원계획 생성)
6. [ ] 카드 접기/펼치기 (기본 펼침/접힘 + 토글 동작)
7. [ ] 카드별 복사 (해당 문장만 복사 + 토스트)
8. [ ] 전체 복사 ([관찰일지 문장]/[보육일지 평가]/[알림장]/[교사 지원계획] 형식)
9. [ ] 문서 저장 (저장 → 완료 토스트)
10. [ ] 문서함에서 다시 열기 (저장한 기록/문서 재확인)
11. [ ] 모바일 화면에서 버튼 크기 확인 (탭하기 충분, 밀림 없음)
12. [ ] 백업 생성 (구글 드라이브 백업 또는 파일 내보내기)
13. [ ] 복원 테스트 (백업 불러오기 → 데이터 복구)
14. [ ] 일반 사용자 관리자 정보 비노출 (엔진명·점수·fallback·내부 라벨 미노출)
15. [ ] 오프라인/네트워크 불안정 시 기본 기능 확인 (생성·복사·저장은 로컬에서 동작)

> 비고: 엔진 전환 설정(legacy/modular)만 백업에 포함되고, 검수 데이터·fallback 로그·user corrections는 백업에서 제외된 상태를 유지한다.
