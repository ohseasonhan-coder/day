# B2 통제형 LLM 구현 보고

## 1. 역할 분리

생성 흐름은 `B2 사실 카드 -> 허용 테마/지원 -> B2 문장 계획 -> 제한형 LLM -> B2 audit -> 채택 또는 B2 fallback`으로 고정했다.

- B2: 관찰내용, 사실 순서, 직접 발화, 허용 의미, 금지 주장, 문장 필드, audit, fallback
- LLM: B2가 허용한 배움 읽기와 미래형 지원 계획의 문장화만 담당
- 일반 사용자 기본 엔진: `rule-b2`
- `auto`: 검토 모드에서만 `private-server-14b -> private-server-7b -> rule-b2` 순서로 선택

## 2. 입력 및 출력 스키마

LLM 입력은 실명을 `원아 A`로 치환한 B2 관찰내용, 직접 발화 배열, 허용 테마/주장, 허용 지원, 금지 주장, 문체 규칙만 포함한다. 원문 자유 입력과 내부 사실 카드 전문은 전달하지 않는다.

출력은 추가 필드를 허용하지 않는 아래 4개 문자열 필드만 받는다.

```json
{
  "learningTheme": "retry",
  "learningReading": "배움 읽기 문장",
  "supportAction": "retry_material",
  "supportAndNextPlan": "미래형 지원 계획 문장"
}
```

머리말, 코드블록, 누락 필드, 추가 필드가 있으면 JSON 오류로 처리한다.

## 3. 허용 범위 검증

- `learningTheme`: B2가 선택한 최대 2개 테마 ID에 포함되어야 함
- `supportAction`: 해당 테마의 지원 ID에 포함되어야 함
- 배움 읽기: 허용 주장 핵심어와 연결되어야 하며 관찰내용을 그대로 반복하면 안 됨
- 지원 계획: 허용 지원 의미와 연결되고 미래 계획형으로 끝나야 함
- 입력에 없고 허용 지원에도 없는 구체 대상, 또래, 재료, 감정은 차단
- 직접 발화를 새로 만들거나 바꾸면 차단
- 감정·의도·발달·능력·성취 단정 및 완료형 교사 지원은 차단

## 4. Audit 및 fallback

LLM 출력은 제한 검증 후 기존 `observationAudit`을 다시 통과해야 한다. 중대 오류가 하나라도 있으면 결과를 폐기한다. 형식 또는 audit 실패 시 같은 제한 문맥으로 최대 1회만 재시도한다. timeout은 재시도하지 않는다. 최종 실패, 서버 미실행, 모델 미발견 시 기록 흐름을 중단하지 않고 즉시 B2 결과를 반환한다.

## 5. 관리자 검토 화면

같은 입력에 대해 다음 세 결과를 비교한다.

1. 기존 규칙 B안
2. B2 규칙 엔진
3. audit를 통과한 LLM 결과

LLM이 실패하면 세 번째 결과는 표시하지 않는다. 자동 안전 점수와 별도로 그대로 사용 가능, 약간 수정, 사실과 다름, 자연스러움, 지원 구체성, 과장/일반론, 발화 훼손, B2 대비 자연스러움·개별성·지원 구체성을 수집한다.

## 6. 저장 범위

로컬 검토 저장 허용 항목은 엔진, 테마 ID, 문장 골격 ID, 선택 여부, 피드백 태그, 수정 여부/수정 섹션, audit 코드와 통과 여부다. 원아 이름, 원문 기록, 관찰/생성 전문, 직접 발화, 자유 메모는 저장하지 않는다. 관련 키는 백업과 동기화에서도 제외한다.

## 7. LoRA 준비 구조

학습은 실행하지 않았다. 후보 데이터는 사실 유형/ID와 플래그, B2 문장 계획, 관찰내용을 제외한 B2/LLM/교사 최종 배움·지원 문장, 수정 사유 태그만 만든다. 이름은 `<CHILD>`, 발화는 `<SPEECH>`로 치환한다.

시작 조건은 비식별 500건 이상, 사실 오류 1% 이하, 반복 수정 유형 3개 이상, 역할 분리 확인, LLM 선호율이 B2보다 5%p 이상, 개인정보 audit 통과로 닫아 두었다.

## 8. 일반 사용자 승격 기준

100건 이상의 실제 교사 검토, 사실 오류 1% 이하, 이름/발화 오류 0건, 사용자에게 노출된 중대 audit 0건, 그대로 사용 비율 5%p 이상 상승, 자연스러움 수정 요구 감소, 긴 서사/은유/감정 변화 사례 개선, p95 15초 이하, fallback 실기기 검증을 모두 만족해야 한다.

현재는 실제 교사 검토와 실모델 품질 데이터가 없으므로 LLM 일반 사용자 승격은 불가하다.

## 9. 검증

- B2 합성/회귀 사례: 105건
- 제한형 LLM: 엄격 JSON, 허용/비허용 테마와 지원, 사실 추가, 감정 추가, 완료형 지원, timeout, 1회 재시도, auto 검토 제한 검증
- LoRA: 원문 관찰, 실명, 직접 발화 제외 검증
- 서버: 14B 우선 선택 및 7B/B2 fallback 검증
- 전체 테스트와 프로덕션 빌드 결과는 작업 완료 시 최종 보고에 기록

## 10. 변경 상태

이번 단계에서는 서식 기능, 출력 형식, 결제 기능을 확장하지 않았다. main 병합, 원격 push, 배포를 수행하지 않는다. 실제 교사 표본과 실모델 비교 결과가 품질 게이트를 충족하기 전까지 기본 엔진은 `rule-b2`로 유지한다.
